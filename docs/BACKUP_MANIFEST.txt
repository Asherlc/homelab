QUICK RECOVERY COMMANDS
================================================================================

View backups:
  ls -lh /mnt/storage/backups/homelab/

Manual backup:
  sudo /opt/scripts/homelab-backup.sh

Restore Sonarr database:
  docker stop sonarr
  cp databases/sonarr/sonarr-YYYYMMDD-*.db /srv/appdata/sonarr/sonarr.db
  chown 1000:1000 /srv/appdata/sonarr/sonarr.db
  docker start sonarr

Force Configarr sync:
  docker restart configarr

Check backup logs:
  tail -50 /var/log/homelab-backup.log

================================================================================
VERIFICATION
================================================================================

To verify backups are working:

1. Check last backup time:
   ls -lt /mnt/storage/backups/homelab/databases/sonarr/

2. Verify backup script ran:
   tail -20 /var/log/homelab-backup.log

3. Confirm containers running:
   docker ps | grep -E 'configarr|authentik-postgres-backup'

4. Test database integrity:
   sqlite3 databases/sonarr/sonarr-LATEST.db "PRAGMA integrity_check;"
